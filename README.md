## Keyboard Shortcuts

- **Open File**： Command / Ctrl + O
- **Close File**： Command / Ctrl + W
- **Play/Pause**: Spacebar
- **Frame Back / Left 15s**： ⬅️
- **Frame Forward / Right 15s**： ➡️
- **Restart**: R
- **Volume Up**： ⬆️
- **Volume Down**： ⬇️
- **Mute**: M
- **Scroll Up / Down （Fast）**： Mouse Wheel or . / ，
- **Scroll （Precise）**： Ctrl / Command + Wheel
